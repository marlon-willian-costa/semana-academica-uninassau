# Pitch de Vendas — 5 minutos (Squad 5)

**Preparação:** abrir o site publicado no projetor e no celular; ter 1 aluno já com 20h para emitir o certificado ao vivo.

| Tempo | Fala / Ação |
|---|---|
| 0:00–0:40 | **A dor.** "Prof. Edson, hoje a Semana Acadêmica vive de lista de papel, planilha e certificado feito um a um. São horas de trabalho e erros de nome." |
| 0:40–1:30 | **Inscrição ao vivo.** Abrir o site no celular, mostrar máscaras, tentar CPF inválido e inscrição duplicada — o sistema bloqueia. Mostrar o QR Code gerado. |
| 1:30–2:30 | **Chamada em segundos.** Painel do professor: ler o QR Code do celular com a câmera → presença registrada. Mostrar a lista e a exportação para Excel. |
| 2:30–3:30 | **Certificado automático.** Consultar um aluno com 20h → PDF gerado na hora com nome e carga horária, enviado por e-mail. Mostrar um aluno com 15h sendo bloqueado. |
| 3:30–4:20 | **Por que somos melhores.** Online (link oficial), seguro (validação, LGPD, anti-duplicidade), testado (23 casos de QA + testes automatizados), feito em equipe (5 squads, Kanban no GitHub). |
| 4:20–5:00 | **Fechamento.** "Zero papel, zero certificado manual, zero erro de digitação. A próxima Semana Acadêmica pode usar isso amanhã." |

**Plano B:** se a internet cair, rodar localmente (`npx serve .`) com os dados de demonstração já cadastrados.
